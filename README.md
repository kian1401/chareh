# 🏙️ شهرکار — پلتفرم خدمات خانگی (معادل عملکردی Urban Company)

سه پرتال کامل در یک کدبیس Flutter — **فارسی و راست‌چین** — با معماری Repository که با یک فلگ از دیتای موک به Firebase واقعی سوییچ می‌کند.

## ✨ چه چیزی ساخته شده

| پرتال | امکانات |
|---|---|
| 🙋 **اپ مشتری** | خانه با بنر و دسته‌بندی‌ها، جستجو + فیلتر، جزئیات سرویس (پکیج‌ها/افزودنی‌ها/نظرات)، فلو رزرو ۳ مرحله‌ای (زمان → آدرس → پرداخت)، پیگیری زنده‌ی سفارش با تایم‌لاین، لغو، امتیازدهی، چت با متخصص، اعلان‌ها، کیف پول، علاقه‌مندی‌ها، **دستیار هوشمند (Gemini)** |
| 🧑‍🔧 **اپ سرویس‌دهنده** | داشبورد (درآمد/کار امروز/امتیاز)، سوییچ آنلاین، **بازار درخواست‌ها** (پذیرش/رد)، روند کاری (پذیرفته ← در راه ← در حال انجام ← تکمیل)، تسویه‌ی درآمد با کمیسیون، پروفایل و مدارک |
| 🛡️ **پنل ادمین** | KPIها (GMV، سهم پلتفرم، سفارش‌های فعال)، نمودار وضعیت‌ها، تنظیم لحظه‌ای کمیسیون، **CRUD سرویس‌ها و دسته‌بندی‌ها**، مدیریت رزروها، تایید/تعلیق متخصصین |

> 🔁 **حلقه‌ی دمو**: سفارشی که در پرتال مشتری می‌سازید **بلافاصله** در تب «درخواست‌ها»ی پرتال متخصص ظاهر می‌شود؛ پذیرش/پیشرفتش هم در اپ مشتری دیده می‌شود.

## 🚀 اجرا

```bash
cd shahrekar
flutter pub get
flutter run -d web-server --web-port 8080   # وب
flutter run                                  # موبایل/شبیه‌ساز متصل
flutter build apk --release                  # خروجی اندروید
```

- ورود: از صفحه‌ی اول یکی از ۳ پرتال را انتخاب کنید؛ در دمو ورود سریع یا **هر کد ۶ رقمی** کار می‌کند.
- سناریوی پیشنهادی: به‌عنوان مشتری «سرویس کولر آبی» را رزرو کنید ← پرتال را عوض کنید (پروفایل ← تغییر پرتال) ← به‌عنوان حسین اکبری سفارش را **بپذیرید** ← مراحل را جلو ببرید ← در اپ مشتری تایم‌لاین و اعلان را ببینید.

## 🔥 اتصال به Firebase واقعی

```bash
flutterfire configure            # firebase_options.dart واقعی را می‌سازد
cd firebase && firebase deploy --only firestore:rules,firestore:indexes,functions
firebase functions:secrets:set GEMINI_API_KEY   # از aistudio.google.com
```

سپس در `lib/core/config/backend_config.dart` مقدار `useMock = false` کنید. هیچ خط دیگری لازم نیست (`docs/` و `firebase/SCHEMA.md` را ببینید).

## 📁 ساختار

```
lib/
├─ core/         تم (بنفش #6D28D9 + وزیرمتن)، روتینگ (go_router)، ابزار فارسی
├─ data/
│  ├─ models.dart          مدل‌ها با toJson/fromJson (Firestore-ready)
│  ├─ repositories.dart    اینترفیس‌های بک‌اند
│  ├─ mock/                MockDb واکنش‌گرا + دیتای فارسی (۱۰ دسته، ۲۲ سرویس، ۸ متخصص)
│  └─ firebase/            پیاده‌سازی واقعی Firebase
├─ shared/widgets.dart     کامپوننت‌های مشترک (کارت سرویس/سفارش، ستاره، وضعیت…)
└─ features/               auth + customer + provider + admin
firebase/                  rules, indexes, functions (OTP، اعلان، امتیاز، درآمد، Gemini)
docs/                      ARCHITECTURE.md و TEAM.md (نقش‌بندی ابزارهای AI + پرامپت‌ها)
```
