# 🛒 سبد خرید زیرساخت ایرانی چاره (قیمت‌های استخراج‌شده مهر ۱۴۰۵)

> هدف: یک MVP واقعی با بک‌اند + دامنه + درگاه + پیامک + مارکت‌های ایرانی.

## 🖥️ ۱) سرور (بک‌اند + دیتابیس + فایل‌ها)
معماری پیشنهادی شروع: **یک VPS لینوکس + Docker** (Node API + PostgreSQL + MinIO/S3 + Nginx + HTTPS)

| گزینه | پیکربندی نمونه | قیمت تقریبی/ماه | منابع |
|---|---|---|---|
| آسیا‌تک (cloud.ir) | ۴هسته/۸گیگ/۱۲۰GB + ۸ ترابایت | ~۳٫۱۵ میلیون تومان | [cloud.ir](https://cloud.ir/service/vps/) |
| آسیا‌تک (asiatech.cloud) | ۴هسته/۸گیگ/۱۲۰GB | ~۱٫۲ میلیون تومان | [asiatech.cloud](https://asiatech.cloud/service/virtual-server) |
| پارس‌پک VPS ایران | از ۱هسته/۱گیگ | از ۸۳۰هزار تومان | [parspack.com/vps](https://parspack.com/vps/iran) |
| ابر آروان | ۱هسته/۱گیگ | ~۹۴۹هزار تومان | [مقایسه skycloud](https://skycloud.ir/compare-cloud-prices) |

✅ **پیشنهاد شروع اقتصادی:** ۲ هسته / ۴ گیگ (~۵۰۰هزار تا ۱م تومان) — بعداً ارتقا بدون انتقال.

## 💳 ۲) درگاه پرداخت
| پذیرنده | کارمزد | نکته |
|---|---|---|
| **زرین‌پال** | ۰٫۵٪ + ۵۰۰ ت (سقف ۱۶هزار ت) | ماه اول رایگان؛ نیاز به اینماد/نماد برای فعال‌سازی کامل |
| **زیبال** | ۱٪ (حداقل ۲هزار، سقف ۲۰هزار) | «درگاه واسط» بدون نماد برای شروع؛ مرچنت `zibal` برای sandbox |
| **آیدی‌پی/پی‌پینگ** | ~۱٪ تا سقف ۴هزار ت | پایین‌ترین هزینه برای MVP |

> کارمزد شبکه شاپرک (۱۲۰–۸۰۰۰ت) جدا است. تسویه به حساب شرکت/فرد روزانه/هفتگی.
> 📌 برای دریافت «مستقیم از شاپرک» (اجاره‌ی): شرکت ثبتی + اینماد لازم است — مرحلهٔ ثابت‌اندیشه بعد از برند.

## ✉️ ۳) پیامک (OTP و اعلان‌ها)
| پنل | تعرفه هر پیامک | نکته |
|---|---|---|
| **کاوه‌نگار** | ~۱۲ تا ۱۷ تومان | بهترین API برای `Verify/Lookup` شی مارل OTP؛ ۵۰هزار ریال اعتبار اولیه رایگان |
| **قاصدک** | ۱۵ تا ۱۹ تومان | پلن رایگان OTP فقط به شماره ثبت‌نام‌شده؛ خط ۳۰۰۰ ۱۴رقمی ۲۵هزار ت |
| **sms.ir** | نزدیک به بالا | UI ساده |
> هر ورود OTP ≈ پا به ۱۵ تومان؛ فاکتور TXN-degree: ۱۰هزار ورود ≈ ۱۵۰هزار تومان.

## 🌐 ۴) دامنه + HTTPS + ایمیل
- `.ir` — نمایندگی‌های ایرنیک، سالیانه سیگونک پنج (زیر ~۱۰۰هزار تومان)
- `.com` — در صورت برندبالی بین‌المللی (~۱۰$/سال، ریالی خرید)
- HTTPS: **Let's Encrypt** رایگان (با Nginx/Certbot)
- CDN + WAF داخلی: **پارس‌پک/اروان** پلن ساده رایگان یا ~۹۹هزار ت/م
- ایمیل سازمانی: Zoho نامدیر/MYIR-G/ایمیل روی کسی‌اف‌خ مطابق سرویس هاست

## 🗺️ ۵) نقشه (برای آدرس/موقعیت سفارش)
- **نشان (Neshan)** یا **مپ (Map.ir)**: سهمیه رایگان برای درخواست‌های محدود با ثبت دولوپر — برای MVP کافی است

## 📱 ۶) انتشار اپ
- **کافه‌بازار** (مارکت اصلی ایرانی) + **مایکت**: پنل دولوپر رایگان/بسیار ارزان، آپلود AAB/APK، هر دو نیازمند مدرک هویتی
- ⚠️ Google Play برای توسعه‌دهندگان ایرانی مسدود/ناموثوق است → نیازی نیست برای ایران

## 🔐 ۷) بکاپ و ذخیره فایل
- ابتکاری: بکاپ روزانه rclone به **باکت آروان/فایل ابری پارس‌پک** (ترابایت باشکوه ≈ هزار ت/م)
