# 🤝 تیم ساخت چاره — نقش‌بندی ابزارهای AI

این پروژه با شبیه‌سازی همکاری ۴ ابزار AI ساخته شده. نقش هر یک و پرامپت‌های آماده:

| ابزار | نقش در تیم | خروجی تحویلی |
|---|---|---|
| 🧠 **Google AI Studio (Gemini)** | مغز هوش مصنوعی | فانکشن `aiAssistant` + پرامپت سیستمی فارسی در `firebase/functions/src/index.ts` |
| 🔥 **Firebase Studio** | مهندس بک‌اند | `firestore.rules`، `firestore.indexes.json`، `functions/`، `SCHEMA.md` |
| 📱 **FlutterFlow ⟵ Flutter** | تیم UI/UX | ۲۰+ صفحه فارسی RTL تحت `lib/features/` در قالب کد استاندارد Flutter |
| 🤖 **OpenHands** | ایجنت اجرایی/معمار | کل کدبیس، آنالیز استاتیک پاک، بیلد وب، مستندات |

---

## پرامپت‌های آماده (اگر خواستی بخشی را در ابزار خودش بازسازی کنی)

### Google AI Studio — تست دستیار
```
تو «چارهی» هستی؛ دستیار فارسی‌زبان اپلیکیشن خدمات خانگی چاره (مشابه Urban Company).
پاسخ‌ها کوتاه و کاربردی؛ قیمت به تومان با اعداد فارسی. حوزه‌ها: نظافت، لوازم خانگی، برق،
لوله‌کشی، نقاشی، زیبایی در منزل، موبایل، اسباب‌کشی. لغو تا ۲ ساعت قبل رایگان است.
سوال کاربر: «قیمت نظافت منزل ۱۰۰ متری چقدر می‌شه؟»
```

### Firebase Studio — تولید/توسعه بک‌اند
```
برای اپ Flutter خدمات خانگی مثل Urban Company، اسکیمای Firestore را با کالکشن‌های
users, services, bookings, providers, earnings بساز؛ Security Rules نقش‌محور
(customer/provider/admin) و Cloud Function تریگر onUpdate روی bookings بنویس که
هنگام completed شدن، درآمد متخصص را با کمیسیون ۱۵٪ ثبت کند.
```

### FlutterFlow — بازآفرینی صفحه‌ی خاص
```
صفحه‌ی جزئیات سرویس (RTL فارسی) بساز: هدر گرادیانی با ایموجی، امتیاز، لیست گزینه‌های
قیمتی به‌صورت کارت‌های رادیویی، افزودنی‌های FilterChip، بخش نظرات، و نوار پایین چسبنده
با «مبلغ قابل پرداخت» و دکمه‌ی رزرو. تم بنفش #6D28D9 و فونت وزیرمتن.
```

### OpenHands — ایجنت کدنویس
```
کامپوننت X را به فلان فایل اضافه کن / باگ Y را لاگ بگیر و با تست رگرسیون درست کن /
این صفحه را به دو تب بشکن... (همان کاری که در این پروژه انجام شد)
```
