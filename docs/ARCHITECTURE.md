# 🏗️ معماری چاره

## نمای لایه‌ها

```
┌───────────────────────────────────────────────────────┐
│ پورتال‌ها (UI)                                        │
│  customer/ + provider/ + admin/  ── go_router shells  │
├───────────────────────────────────────────────────────┤
│ وضعیت (State)                                         │
│  AuthState (ChangeNotifier + provider)                │
│  بقیه: StreamBuilder روی استریم‌های ریپازیتوری        │
├───────────────────────────────────────────────────────┤
│ ریپازیتوری‌ها (انتزاع)  lib/data/repositories.dart     │
│  Auth • Catalog • Booking • Provider • Chat • Misc    │
├──────────────────────┬────────────────────────────────┤
│ mock/ (MockDb)       │ firebase/ (Firestore+Auth+CF)  │
│ دیتای فارسی + استریم │ پیاده‌سازی واقعی production     │
└──────────────────────┴────────────────────────────────┘
        ▲ تعویض فقط با یک فلگ: BackendConfig.useMock
```

## چرا Repository Pattern؟
- **دمو فوری** بدون سرور (موک) و **سوییچ تمیز** به Firebase با تغییر یک خط.
- UI هیچ‌وقت Firebase را import نمی‌کند → تست‌پذیری و قابلیت جایگزینی بک‌اند (Supabase/REST اختصاصی).

## الگوی استریم موک (شبیه‌سازی Firestore)
`MockDb.streamOf(read)` ابتدا مقدار فعلی را yield می‌کند و بعد هر تغییر (mutation) همه‌ی کوئری‌های باز را دوباره می‌خواند — دقیقاً مثل `snapshots()` در Firestore. برای همین سفارشی که مشتری می‌سازد **بلافاصله** در پورتال متخصص (درخواست‌های بازار) ظاهر می‌شود.

## جریان‌های کلیدی
1. **رزرو**: service → options/addOns → زمان → آدرس → پرداخت → `createBooking` (pending) → متخصص accept → مشتری پیگیری → completed → امتیاز.
2. **درآمد**: تکمیل سفارش × (1 − کمیسیون) → earnings متخصص → تسویه.
3. **دستیار AI**: اپ → Cloud Function `aiAssistant` → Gemini API؛ در حالت موک: موتور قاعده‌محور فارسی.

## تصمیم‌های فنی
| موضوع | تصمیم | دلیل |
|---|---|---|
| i18n | رشته‌های فارسی مستقیم + `Locale('fa')` | MVP تک‌زبانه؛ بعداً easy_localization |
| تقویم | برچسب‌های نسبی (امروز/فردا/روز هفته) | بدون وابستگی به تقویم جلالی در MVP |
| عکس‌ها | گرادیان + ایموجی به‌جای URL | بدون وابستگی شبکه/حقوق عکس؛ جایگزینی آسان با Storage |
| نمودار ادمین | بارچارت دست‌ساز | حذف وابستگی سنگین برای MVP |
| google_fonts | پین‌شده روی 6.3.3 | نسخه‌ی ۹ به material_ui مهاجرت کرده و ناسازگار است |
